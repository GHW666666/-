# 奶娃快跑 - 微信小游戏 / 抖音小游戏 移植指南

本项目在底层架构上采用了 **纯原生 Canvas 2D 渲染引擎 + 平台抽象层（`game/adapter.js`）** 设计，因此：
- ❌ **完全不依赖任何 DOM 标签（无需 `document.createElement` 等浏览器专属 API）**
- ❌ **完全不依赖任何庞大的第三方外部框架（包体仅数百 KB，秒开加载）**
- ✅ **100% 完美契合微信小游戏（`wx`）和抖音小游戏（`tt`）的运行沙箱**

---

## 移植步骤一：移植到微信小游戏

1. **下载并打开【微信开发者工具】**
   - 选择导入项目，选择新建或导入 **“小游戏”** 类型。
2. **复制文件结构**
   将本项目的以下文件与目录拷贝到微信小游戏工程根目录：
   ```
   ├── game/               # 游戏核心逻辑（player.js, world.js, ui.js 等）
   ├── assets/             # 游戏图片资源（frog_player.png, coin.png 等）
   ├── game.js             # 小游戏启动入口（直接使用 minigame/game.js 放入根目录）
   ├── game.json           # 小游戏配置文件（直接使用 minigame/game.json 放入根目录）
   └── project.config.json # 工程配置（直接使用 minigame/project.config.json 放入根目录）
   ```
3. **AppID 设置**
   - 在微信开发者工具中填入你在微信公众平台申请的 **小游戏 AppID**（测试阶段可先选“测试号”或游客模式）。
4. **点击“编译”即可在开发者工具中即时预览**，点击“真机调试”扫描二维码即可在手机微信中丝滑试玩！

---

## 移植步骤二：移植到抖音小游戏（字节跳动小游戏）

1. **下载并打开【抖音开发者工具】（ByteDance DevTools）**
   - 新建或导入项目，类型选择 **小游戏**。
2. **复制文件结构**
   - 与微信小游戏完全一致！将 `game/`、`assets/`、`game.js`、`game.json` 拷贝到抖音工程根目录下。
   - `game/adapter.js` 内部已自动实现了 `typeof tt !== 'undefined'` 的抖音 API 自动识别与无缝挂载。
3. **AppID 设置**
   - 填入抖音开放平台申请的小游戏 AppID。
4. **编译与预览**
   - 点击预览并用手机抖音 App 扫码，即可在抖音端内直接畅玩！

## 架构优势与商业化对接预留

1. **激励视频广告接入**：
   - 微信端：调用 `wx.createRewardedVideoAd({ adUnitId: 'xxxx' })`
   - 抖音端：调用 `tt.createRewardedVideoAd({ adUnitId: 'xxxx' })`
   - 可以在玩家死亡时提供“看广告满血复活 / 获得超级奶瓶冲刺”的鬼畜互动点！
2. **社交分享与排行榜**：
   - `platform.js` 中已预留了存储和数据对接，微信开放数据域可直接绘制好友排行榜。
