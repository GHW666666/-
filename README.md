# 🍼 奶娃跑跑 (Naiwa Runner) 🏃

> **中国互联网魔性鬼畜跑酷小游戏** —— 经典《地铁跑酷》三轨玩法，融合“大头奶娃”与“牛来！速归！”魔性互联网热梗。  
> 专为 **微信小游戏** 与 **抖音小游戏** 双端打造，支持 H5 极速本地预览与一键多端发布。

---

## 🎮 游戏核心玩法与特色

### 1. 经典三轨跑酷机制
- **三车道切换**：支持极速换轨并带有拟真的侧倾动态手感。
- **跳跃（Jump）**：向上滑屏，跨越低矮路障、跳上集装箱车顶。
- **滑铲（Slide）**：向下滑屏，身体贴地滑铲穿过高空横木与障碍；空中下滑可急速下坠落地。
- **速度递增**：随奔跑距离提升，速度由 18 m/s 递增至 38 m/s，越往后越刺激！

### 2. 互联网鬼畜热梗元素
- **主角【奶娃】**：
  - 经典魔性大头、咬着亮色奶嘴、身穿喜庆红肚兜/尿不湿。
  - 奔跑时小短腿做风火轮般夸张摆动，跳跃时凌空蹬腿，滑铲时贴地滑行。
- **追击者【牛来】（替代地铁保安）**：
  - 一头体格健硕、眼睛冒红光、戴着大金鼻环的暴走狂暴大野牛紧追身后。
  - **紧逼警告**：当玩家磕碰障碍物时，神牛瞬间逼近到玩家屁股后方 1 米处，发出“哞！/牛来！”警报与震动！若 4.5 秒内再次失误，直接一头顶飞扑街！
- **神级道具【牛市降临 / 牛来附体】**：
  - 拾取金光闪闪的神牛令，主角瞬间进入无敌冲撞模式，满屏红光暴涨，直接撞飞沿途所有障碍物并吸光奶瓶！
- **魔性道具库**：
  - 🍼 **兽奶瓶**：基础金币收集物，拾取清脆啾啾声。
  - 🧲 **吸奶器（磁铁）**：10秒全轨道奶瓶自动吸附。
  - 🚀 **窜天猴（双筒火箭）**：加速冲刺并获得无敌保护。

## 🛠️ 技术架构与双端移植设计

本项目采用 **核心玩法与平台接口完全解耦** 的现代化架构：

```text
├── src/
│   ├── platform/
│   │   ├── Platform.js       # 跨平台桥接层 (自动识别微信 wx / 抖音 tt / 浏览器 H5)
│   │   └── AudioSynth.js     # 程序化实时音频合成 (0外部文件依赖，秒开无延迟)
│   ├── core/
│   │   ├── Renderer.js       # Three.js 场景、卡通光照、远景迷雾与跟随相机
│   │   └── InputManager.js   # 触摸滑屏手势、鼠标滑动、键盘(WASD/方向键)监听
│   ├── entities/
│   │   ├── BabyPlayer.js     # 主角奶娃 3D 模型与物理控制
│   │   ├── BullChaser.js     # 追击者牛来 3D 模型与紧逼机制
│   │   ├── Obstacle.js       # 低障/高障/全阻挡车厢/斜坡跳板
│   │   └── Collectible.js    # 兽奶瓶与各类道具
│   ├── world/
│   │   └── TrackManager.js   # 三轨道无限跑道地形分块循环
│   ├── ui/
│   │   └── UIManager.js      # 响应式 HUD、预警横幅、结算与广告复活弹窗
│   └── game/
│       └── Game.js           # 游戏主循环、碰撞检测与全流程状态机
├── tools/
│   └── build-minigame.js     # 小游戏一键打包脚本
├── game.json                 # 微信/抖音小游戏主配置文件
├── project.config.json       # 微信开发者工具工程配置
└── index.html                # 本地 H5 极速调试入口
```

### 平台移植亮点
1. **微信小游戏**：支持微信好友排行榜、微信分享卡片、看激励视频广告复活。
2. **抖音小游戏**：内置 `tt.getGameRecorderManager`，**支持游戏精彩对局一键录屏分享到抖音带话题**（爆款获客核心手段）。
3. **本地 H5**：直接在浏览器无缝双击预览，自带模拟广告与调试工具。

## 🚀 快速启动与开发

### 1. 安装依赖
```bash
npm install
```

### 2. 启动本地 H5 实时开发预览
```bash
npm run dev
```
启动后在浏览器打开控制台或访问 `http://localhost:3000` 即可开始跑酷试玩。

### 3. 构建发布小游戏工程
```bash
npm run build:minigame
```
执行后会在 `dist-minigame/` 生成符合微信和抖音小游戏规范的发布包。

### 4. 导入小游戏开发者工具
- **微信小游戏**：打开【微信开发者工具】，选择“导入项目”，目录选择当前项目根目录或 `dist-minigame`。
- **抖音小游戏**：打开【字节跳动开发者工具】，选择“导入小游戏”，目录同样直接导入即可。
