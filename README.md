# 奶蛙快跑

Three.js 3D 跑酷游戏，提供浏览器入口与微信小游戏构建，支持三车道换道、跳跃、滑铲和高台奔跑。

## 直接试玩

双击根目录 `index.html`，或者 `dist/index.html`。点击「地图 / 切换地图」选择世界，点击「衣橱」试穿衣服、装备翅膀，点击「成就」查看记录。

## 主页面与成就

小游戏的画面与界面按设备像素密度绘制，最高 3 倍且限制总像素为 400 万；首页镜头固定，保留角色待机动作。跑酷中的左下速度卡片使用网页版的深色双行样式、m/s 单位和彩色状态。

微信开发者工具运行请执行 `npm run build:minigame`，然后导入工程根目录并选择「小游戏」。根目录 `project.config.json` 指向 `minigame/`，其中的 `game.js`、`game.json` 是小游戏启动入口；详细说明见 [微信小游戏说明](minigame/README_PORTING.md)。

微信头像可选用 [512×512 压缩 JPEG](assets/icons/naiwa-avatar-v4-wechat-512.jpg)，约 66KB：奶蛙展开奶油云翼，在埃及列车屋顶跃过跨栏。保留[设计提示词](assets/icons/naiwa-avatar-v4-prompt.txt)供后续调整。

顶部左侧显示可用金币，右侧显示最远距离。成就页记录最远距离、累计获得金币、完成跳跃与完成滑铲次数，并保存到本地。跳跃落地、滑铲结束才计数；重复按键不会重复计数，死亡或飞行打断的动作不计。

地图、衣橱、成就、排行和补给入口位于「开始跑酷」下方。排行榜只收录自己的成绩，按距离、单局金币和完成时间排序，保留最好的 20 局；结束、重新开始或从暂停返回主页面时保存一次。暂停后继续同一局不会重复记录，主页补给金币不会算进单局成绩。旧的最远距离显示为「历史最佳记录」，不补造过去的局数、日期或金币数。

首次更新会导入已保存的最远距离和现有金币余额；过去未记录的金币收入、跳跃及滑铲无法补算，之后持续累计。

## 衣橱与试穿

衣橱分为「衣服」和「翅膀」两栏，服装可按日常和怪趣筛选。衣服包含原味奶蛙、桃桃护理员、午夜小偷、薄荷校队，以及 UFO 临时工、雪花电视怪、深海果冻、孢子观察员、肚皮吞金兽和逃跑小笼包。衣服和翅膀可独立搭配。

点选卡片立即显示实际 3D 造型，左右滑动角色可以旋转 360°，也可使用旋转按钮或恢复正面。卡片列表支持横向滑动。未解锁的造型也能免费试穿；购买会扣除金币、永久解锁并立即装备，已购买的款式切换不再收费。余额不足时显示还差多少金币。关闭衣橱会恢复已装备造型。

## 地图与玩法

| 地图 | 场景 | 赛道挑战 |
| --- | --- | --- |
| 埃及·砂岩集市 | 金字塔、法老、棕榈与砂岩集市 | 斜坡登车顶、跨栏、滑铲 |
| 巨物便利店 | 奶盒屋、圆饼干罐屋、冰柜屋，搭配街铺、货架和巨大食品 | 沿中间道收集三枚金币 |
| 奶茶泡泡港 | 奶茶杯屋、茶壶屋、叠杯塔，搭配茶屋、码头和珍珠岛 | 珍珠垫弹起，穿过三个空中泡泡环 |
| 蛙塘音乐节 | 荷叶亭、巨型音箱舞台屋、莲花展馆，搭配舞台、灯串和芦苇 | 按左、中、右顺序换道踩节拍 |
| 云端洗衣房 | 洗衣机屋、编织篮屋、巨衣晾晒阁，搭配晾衣楼、阳台和云海 | 暖风托举收袜子，也可沿坡上安全晾衣台 |

四张新地图每 48 米、每侧有 10 栋建筑（8 栋特色建筑、2 栋普通街铺）与 4 个主题大件，分为近景和中景两层；近景每 6 米、中景每 8 米一个位置。挑战段与随机障碍分开安排；命中每个目标奖励 2 金币，三个连续全中额外奖励 12 金币，错过目标不会造成伤害。

五张地图混合出现小汽车、加长巴士、货车和原有列车或主题车体。小汽车可以换道避让或跳过；沿坡道能跑上巴士、货车屋顶，长车顶随机安排两道地面同款栏杆，包含连续跳跃、连续滑铲和高低栏交替组合。低矮挡栏需要跳跃，架高的横杆需要滑铲。

长车在跑酷距离中长 220 米，两栏位于登顶后的 40 米和 140 米；间距 100 米，在最快 65 米/秒时也有约 1.54 秒，可完成弹簧鞋跳跃后再做下一次动作，第二栏后还保留 80 米车顶供落地。整段坡道、车体和 35 米落地区域会被预留，后续障碍与挑战不叠入；长车存在时，后续迎面列车保持静止，避免驶入车顶挑战。原有短列车的单栏距入口 10 米，所有栏杆宽度适配屋顶并随车移动。奶蛙奔跑时双臂与步伐交替摆动，手掌在胯侧露出。

## 翅膀系统

「奶油云翼」需用 10000 金币解锁，购买后衣橱可以装备或卸下。未购买翅膀也可拾取赛道羽毛激活 8 秒临时飞行：奶蛙肚皮朝下，左右换道收集三条空中金币线；空中航道位于门架上方，没有伤害障碍。飞行结束后回到已装备外观，自动降落、清空落地危险障碍并提供短暂保护，保留安全支撑平台。

羽毛首次在约 600–900 米安排，之后随机间隔约 1100–1600 米；若遇到挑战段，会延后到挑战结束后的安全区域。

翅膀外观登记在 `game/wings3d.js` 的 `WING_SKINS`，模型与飞行规则分开，后续可扩展皮肤。当前只有奶油云翼，价格只使用游戏金币。

## 背景音乐

原创配乐[《奶蛙的晴天小跑》](assets/audio/naiwa-sunny-run.mp3)为 124 BPM、约 62 秒的无歌词循环：木琴主旋律、轻柔弹拨和弦、暖低音与轻鼓点。点击出发播放，暂停时保留进度，再次挑战从头播放；静音、返回首页或切到后台会停音乐。浏览器直接播放本地文件，微信使用代码包内的原生音频播放器，原有金币与动作音效保留。

MP3 约 969KB，小游戏构建只复制这一份压缩音乐。WAV 母带可由脚本生成到 `output/music/naiwa-sunny-run.wav`，不纳入仓库或发布包。乐谱与合成脚本分别为 `scripts/naiwa-music-score.mjs`、`scripts/render-naiwa-music.mjs`，安装 FFmpeg 后可执行 `node scripts/render-naiwa-music.mjs --ffmpeg <FFmpeg路径>` 重新导出。

## 开发命令

```bash
npm install
npm run dev
npm run build:browser
npm run build:minigame
npm test
npm run build
```

`dev` 构建后启动本地服务；修改源码后执行 `build:browser` 再刷新。`build` 更新根目录浏览器脚本并生成 `dist/`。脚本包含依赖，因此双击页面也能运行。

## 目录

- `game/main.js`：状态、碰撞、存档和总循环。
- `game/character3d.js`、`frogGeometry.js`：奶蛙模型与动作。
- `game/outfits3d.js`：服装皮肤、帽子及配饰。
- `game/wardrobePreview3d.js`：旋转试穿、展台和预览镜头。
- `game/achievements.js`：成就计数、本地保存及旧数据导入。
- `game/runRecords.js`：本人成绩榜、单局记录排序及旧最佳记录导入。
- `game/wardrobeInventory.js`：金币钱包、造型购买与永久解锁、每日补给。
- `game/player3d.js`：移动、跳跃、滑铲、飞行与落地物理。
- `game/world3d.js`：灯光、镜头、场景与实体生成、回收。
- `game/vehicles3d.js`：小汽车、巴士和货车模型，共享几何与各地图车漆。
- `game/themeEnvironment3d.js`、`themeArchitecture3d.js`：四地图布局与建筑。
- `game/everydayArchitecture3d.js`：奶盒、饼干罐、冰柜、奶茶杯、茶壶与叠杯特色建筑。
- `game/dreamArchitecture3d.js`：荷叶、音箱、莲花、洗衣机、编织篮与晾晒阁特色建筑。
- `game/*Props3d.js`：各主题装饰模型库。
- `game/trackChallenges3d.js`：四地图的挑战与连击奖励。
- `game/wings3d.js`、`wingFlight3d.js`：翅膀外观、羽毛与空中金币航道。
- `game/ui.js`、`audio.js`、`adapter.js`：界面、音效、输入与平台接口。
- `game/browserEntry.js`：源码启动入口；`browser.bundle.js` 是自动生成文件。
- `assets/`：运行音乐与最终头像；旧参考截图已清理。
- `libs/`：本地 Three.js；`tests/`：模型、场景、挑战和飞行行为验证。
- `minigame/`：微信小游戏入口、运行适配与 Canvas 界面；`game.js` 由 `build-minigame.mjs` 自动构建。

## 操作

左 / 右方向键或 A / D 换道，上方向键 / W / 空格跳跃，下方向键 / S 滑铲；触屏可滑动或使用底部按钮。飞行中左右换道有效，跳跃与滑铲不会打断飞行。
